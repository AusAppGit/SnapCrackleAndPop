# SnapCrackleAndPop
A code response to Sololearn's Code Coach Challenge titled, "Snap, Crackle And Pop". 
The code should take 6 integers as input, each on a new line. Should the integer be perfectly divisible by 3, output "Pop".  Should the integer not be divisible by 3 and is an odd number, output "Snap", otherwise output "Crackle".
Output is a string, with each noise in order followed by a space.
